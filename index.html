Metode yang dapat dijelaskan

Setiap fitur dibangun dari hubungan fisik yang eksplisit.

Model inti

Bilangan gelombang diselesaikan secara iteratif menggunakan Newton–Raphson. Dari nilai k, aplikasi menurunkan panjang, kecepatan fase, dan kecepatan grup.

ω² = gk tanh(kh)Hubungan dispersi gelombang linear pada kedalaman terbatas.
L = 2π/k  ·  C = L/TPanjang gelombang dan kecepatan fase.
Cg = ½[1 + 2kh/sinh(2kh)]CKecepatan grup yang membawa energi gelombang.
E = ⅛ρgH²  ·  P = ECgEnergi rata-rata gelombang reguler dan daya per meter puncak.

Asumsi dan batas model

Model dibuat untuk pembelajaran awal. Kejujuran terhadap batas model lebih bernilai daripada menampilkan presisi palsu.

  • Gelombang dianggap periodik, dua dimensi, dan beramplitudo relatif kecil.
  • Fluida dianggap homogen, tak termampatkan, dan tidak mengalami viskositas.
  • Shoaling memakai konservasi fluks energi tanpa kehilangan energi.
  • Refraksi memakai hukum Snell dengan kontur kedalaman sejajar.
  • Pecah gelombang diperiksa dengan batas Miche dan rasio H/h.
  • API prakiraan adalah keluaran model global, bukan pengukuran buoy lokal.
Catatan penting: “Arah rambat” pada simulator menunjukkan tujuan pergerakan gelombang. API umumnya melaporkan arah asal gelombang, sehingga aplikasi membaliknya 180° ketika data dimuat ke simulator.
